# Toán Vui Tiểu Học 4-5 (Math Buddy 4-5)
Ứng dụng Web Học Tập & Đồng Hành Toán Học Chuẩn Chương Trình GDPT 2018 (Lớp 4 & Lớp 5)

## 🌟 Tính Năng Nổi Bật
1. **Luyện tập theo chuẩn GDPT 2018:**
   - **Lớp 4:** Số tự nhiên lớn, Phân số kỳ diệu, Hình học (Hình bình hành, hình thoi), Toán có lời văn (Tổng - Tỉ, Tổng - Hiệu).
   - **Lớp 5:** Số thập phân, Tỉ số phần trăm & Giảm giá thực tế, Hình học không gian (Hình thang, hình tròn, hình hộp), Toán chuyển động đều ($s = v \times t$).
2. **Linh Vật Trợ Lý AI Đồng Hành (Cú Vàng Poki):**
   - Đọc to đề bài bằng giọng nói tiếng Việt chuẩn (Web Speech Synthesis API).
   - Biểu cảm linh hoạt, phản hồi tích cực và đưa ra lời khuyên từng bước.
3. **Bảng Nháp Vẽ Tay Tương Tác (Smart Scratchpad):**
   - Canvas đa màu sắc, bút chì, tẩy và xóa nháp giúp học sinh vẽ sơ đồ đoạn thẳng và đặt tính tự do.
4. **Đấu Trường Tính Nhẩm Siêu Tốc 60 Giây (Speed Arena):**
   - Đề bài sinh ngẫu nhiên theo thuật toán, hệ thống Combo nhân điểm, âm thanh chiến thắng và bảng kỷ lục.
5. **Thám Hiểm Đảo Toán Học (Adventure Map):**
   - 6 ải thử thách mở khóa theo cấp độ Sao, thu thập huy hiệu danh dự.
6. **Báo Cáo Học Tập & Phiếu Khen Thưởng:**
   - Đánh giá độ thành thạo kỹ năng, xếp hạng danh hiệu và hỗ trợ in trực tiếp phiếu khen cho phụ huynh/giáo viên.

## 🚀 Khởi Chạy Ứng Dụng
- **Tự động dò cổng trống:** Chạy `start-app.bat` (Windows) hoặc `node start-server.js` (Linux).
- Cổng mặc định ưu tiên: `4350` (tự động chuyển dải `4350 - 4399` nếu cổng bận).
- Build production: `npm run build` -> thư mục `dist/`.
